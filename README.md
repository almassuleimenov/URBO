# URBO coffee — сайт

Next.js 16 (App Router) · Tailwind v4 · Motion · Lenis · MapLibre GL (тайлы OpenFreeMap, без API-ключа).

```bash
npm install      # заодно копирует воркер MapLibre в public/vendor
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Что на странице

| Секция | Файл | Анимация |
|---|---|---|
| Интро (1 раз за сессию, клик или клавиша пропускают) | `components/Intro.tsx` | буквы URBO поднимаются из маски, велосипед рисуется линией, разгоняется по дороге и уезжает вправо, две шторки (бордо и персик) уходят вверх |
| Hero | `components/Hero.tsx` | построчное появление заголовка, фото открывается шторкой, велосипед катится вместе со скроллом, бейдж ускоряется от скорости прокрутки |
| Бегущая строка | `components/Marquee.tsx` | скорость и направление зависят от прокрутки, при наведении замедляется |
| Манифест | `components/Manifesto.tsx` | слова проявляются и «садятся» на строку по мере прокрутки |
| Меню | `components/Menu.tsx` | вкладки с перетекающей «пилюлей», фото меняется шторкой, строки появляются каскадом |
| Как мы варим | `components/Process.tsx` | закреплённая горизонтальная лента (на телефоне — свайп), прогресс показывает едущий велосипед |
| Карта кофеен | `components/BranchMap.tsx` | карта в цветах бренда, пины с велосипедом и пульсом; наведение — подсказка, клик — пролёт к кофейне с наклоном и карточка с маршрутом в 2GIS; поиск, фильтр по городу, «Рядом со мной», статус «открыто/закрыто» по времени Алматы |
| VIP-комнаты | `components/Spaces.tsx` | фото открываются шторкой, параллакс внутри рамки |
| Франшиза | `components/Franchise.tsx` + `app/api/franchise/route.ts` | форма заявки с проверкой полей, экран «Заявка у нас» |
| Работа в URBO | `components/Jobs.tsx` | названия должностей поднимаются из маски, строка заливается при наведении, ссылка в Instagram |
| Частые вопросы | `components/Faq.tsx` | аккордеон: плавная высота, «+» превращается в «−» |
| Футер | `components/Footer.tsx` | буквы URBO поднимаются, велосипед едет по их кромке |
| Панель на телефоне | `components/ActionBar.tsx` | «Найти кофейню / Меню» внизу экрана после hero, прячется на карте, в форме и футере |

**Велосипед** (`components/RidingBike.tsx`) — один компонент для hero, ленты процесса и футера: колёса вращаются ровно
по пройденному пути, педали крутятся через передачу и остаются горизонтальными, велосипед наклоняется при разгоне
и торможении, слегка покачивается на ходу, разворачивается при прокрутке назад, на скорости появляются линии
движения. При наведении (или тапе) — вилли.

**Типографика**: `lib/typo.ts` ставит неразрывные пробелы после коротких слов и перед тире, чтобы предлоги
не висели в конце строки.

При системной настройке «уменьшить движение» всё показывается сразу, без сдвигов.

## Что нужно заменить перед запуском

1. **Филиалы** — `src/data/branches.ts`. Сейчас 16 точек-заглушек: улицы настоящие, но адреса и координаты
   примерные, часы условные. Сайт urbocoffee.kz не отдал данные автоматически. Нужны реальные: название, улица,
   район, часы, координаты `[долгота, широта]`.
2. **Меню и цены** — `src/data/content.ts`. Позиции и цены условные.
3. **Фотографии** — сейчас стоят временные кадры с Wikimedia Commons (`public/assets/img/`, авторы — на `/credits`).
   Нужна собственная съёмка: фасад и зал, бар, завтраки, боулы, VIP-комнаты. После замены уберите ссылку
   на `/credits` в футере.
4. Часы «с 7:30–8:00 до 22:00–23:00» в футере — предположение, проверьте.
5. **FAQ, вакансии, франшиза** — `src/data/extra.ts`. Ответы (оплата, Wi-Fi, молоко), описания должностей
   и что входит во франшизу — заглушки, сверьте с URBO.
6. **Заявки на франшизу** — `src/app/api/franchise/route.ts` сейчас только проверяет поля и пишет заявку в лог
   сервера. Подключите доставку (CRM, Telegram-бот или почту) — место отмечено `TODO`.
